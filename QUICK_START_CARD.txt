## KEY COMMANDS

```bash
# Virtual environment
python -m venv venv                    # Create venv
venv\Scripts\Activate.ps1             # Activate (PowerShell Windows)
deactivate                             # Deactivate

# Package management
pip install -r requirements.txt         # Install all packages
pip freeze > requirements.txt           # Save installed packages
pip list                               # List installed packages

# Snowflake test
python -c "from snowflake_connector.connector import SnowflakeConnector; print('OK')"

# Testing
pytest tests/ -v                       # Run all tests
pytest tests/test_connector.py -v      # Run specific test file
pytest tests/ -v --cov                 # With coverage report
pytest tests/ -x                       # Stop at first failure

# Git
git init                               # Initialize repo
git add .                              # Stage all changes
git commit -m "message"                # Commit
git log --oneline                      # View history
git status                             # See what's changed

# Flask development
python backend/app.py                  # Start dev server (http://localhost:5000)
curl http://localhost:5000/api/health  # Test endpoint
```

## STRESS-FREE SUCCESS TIPS

1. **One phase at a time**
   - Complete Phase 1 fully before starting Phase 2
   - All tests passing before moving on

2. **Commit frequently**
   - Commit after each completed task
   - Creates checkpoint to rollback to

3. **Test early**
   - Write tests as you code
   - Catch bugs before they compound

4. **Read error messages**
   - Python tracebacks are your friend
   - 80% of errors are clearly explained in the message

5. **Use debugger**
   - Don't just print-debug
   - Learn VS Code debugger early
   - Saves hours overall

6. **Take breaks**
   - Mental fatigue kills productivity
   - 50 min work + 10 min break = better progress

7. **Learn by doing**
   - Don't just read code
   - Type it out yourself
   - Mistakes = learning

8. **Celebrate wins**
   - First passing test? Celebrate!
   - First API call works? Celebrate!
   - Small wins add up

## HELP! I'M STUCK

**Problem** → **Look Here**

- "ModuleNotFoundError" → `pip install [package]`
- "ImportError" → Make sure in venv, pip installed packages
- Snowflake won't connect → Check .env file, credentials
- Test fails → Read error message, use debugger
- Flask won't start → Check port 5000 not in use
- Frontend can't reach API → Check CORS, Flask config
- Don't understand concept → `02_LEARNING_RESOURCES.md`
- Don't know what to do next → `03_IMPLEMENTATION_CHECKLIST.md`
- Don't understand architecture → `00_PROJECT_PLAN.md` Section 1
